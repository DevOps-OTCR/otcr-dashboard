# Layouts and Density

A slide has one job. Layout serves that job; it does not decorate it.

**Never shrink the font to fit. Split the slide.**

---

## 1. Layout library

| Layout | Use for | Structure |
|---|---|---|
| **Action title + text** | Recommendation, executive summary | Title, 3 short blocks or 3 lines |
| **Action title + exhibit** | Most analytical slides | Title, exhibit ~60–70% of body, source |
| **Two-panel comparison** | Option A vs B, before/after | Title, left/right with matched scales |
| **3-column** | Three reasons, three segments | Title, three equal columns, one message each |
| **Timeline / roadmap** | Sequence, phases | Title, horizontal axis, owners under each phase |
| **Matrix** | 2×2 positioning | Title, defined axes, labelled quadrants |
| **Waterfall** | Drivers of change | Title, bridge, annotated start/end |
| **Stat callout** | One number is the message | Title, one large figure, one-line interpretation |
| **Quote / evidence** | Voice of customer | Title, short quote, attribution |
| **Process flow** | How something works | Title, ≤7 boxes, one decision point |
| **Table** | Options × criteria | Title, ≤7 rows, highlighted recommendation |
| **Divider** | Section break (long decks only) | Number + section claim |

Pick the layout **after** the message and exhibit are decided. A layout chosen first will bend the argument to fit it.

---

## 2. Density thresholds

| Element | Limit | If exceeded |
|---|---|---|
| Message per slide | 1 | Split |
| Supporting points | 3 | Cut or move to appendix |
| Bullets per point | 3 | Promote to a sub-slide |
| Words in an action title | ~15 | Rewrite |
| Series in a chart | 5 | Small multiples |
| Rows in a table | 7 | Appendix |
| Font size | ≥16pt body, ≥12pt footnote (presentation) | Split |
| Source line | Always present | Add it |

A slide the audience reads instead of listening to is a document page. Move the prose to speaker notes.

---

## 3. Visual hierarchy

Four levels, consistently applied across the deck:

| Level | Element | Weight |
|---|---|---|
| 1 | Action title | Largest, darkest |
| 2 | Section or slide claim support | Medium |
| 3 | Body / exhibit labels | Regular |
| 4 | Source and footnote | Smallest, grey |

If everything is bold, nothing is. Emphasis is a scarce resource: one per slide.

---

## 4. Anti-monotony rule

Beyond ~8 slides, vary the form:

- At least **4 different layout types** across the body.
- No more than **2 consecutive slides** with the same layout.
- At least one **single-number or quote** slide to break analytical rhythm.

Monotony is not a style problem; it signals that every slide is doing the same job, which usually means the argument is flat.

---

## 5. Alignment and spacing

| Rule | Detail |
|---|---|
| One grid | Same left margin, same title baseline, every slide |
| Consistent gutters | Equal spacing between columns and blocks |
| Optical alignment | Text aligns to the grid, not to the box |
| Whitespace is content | Breathing room signals confidence |
| No centred body text | Left-align for reading; centre only titles if the template requires it |
| Consistent title height | Titles of different lengths must not shift the body |

---

## 6. Typography

| Rule | Detail |
|---|---|
| One typeface family | Two weights maximum |
| Sentence case titles | Easier to read than Title Case |
| No all-caps body | Slows reading |
| No italics for emphasis | Use bold, sparingly |
| Numbers aligned | Right-align figures in tables; use tabular numerals |
| No text over images | Unless a scrim guarantees contrast |

## 7. Colour

- Maximum 3 colours: base, accent, grey.
- Accent marks the point being made, nothing else.
- Red/green only with a second cue (symbol, label) — accessibility.
- Check contrast; grey text on white is often too light.
- Same colour = same meaning for the entire deck.

---

## 8. Speaker notes

Use notes when the slide depends on context the audience cannot see:

- The method behind a number.
- The objection the presenter expects.
- The transition to the next slide.

Do not write a script. A presenter reading notes is not presenting.

---

## 9. Layout QA

- [ ] One message, stated in the title
- [ ] Layout matches the message type
- [ ] Nothing overflows the slide boundary
- [ ] Title fits on one line (or is deliberately two)
- [ ] Body text ≥16pt
- [ ] Source line present and legible
- [ ] Consistent margins with the rest of the deck
- [ ] No more than 2 consecutive slides with the same layout
- [ ] Accent colour used once per slide
- [ ] No decorative element that carries no information
